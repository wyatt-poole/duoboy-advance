# Roadmap

Rough order, not promises. Ideas and help are welcome; see [CONTRIBUTING.md](CONTRIBUTING.md).

## Next
- **Launcher** at startup to pick a game, with per-game home-screen shortcuts
- **App icon**
- **Touch keyboard** on the bottom screen for naming (3DS style)
- **Area / DexNav view**: the wild Pokémon of your current area, by method and time of day, with a Pokédex entry. An experimental version is in the code (debug builds); it should follow the game's own DexNav: available once unlocked in-game, with features unlocking as the game unlocks them.
- **Battle intro** animation on the bottom screen during the transition
- **Pause menu** on the bottom screen with d-pad and touch

## Later
- **More games**: vanilla FireRed / LeafGreen, Emerald, Ruby / Sapphire, and other FireRed-based hacks, through per-game profiles
- **RetroAchievements browser** from the home screen: scroll, search, sort, compare, details
- Built-in list of ROM-hack patches to download (patches only; you always bring your own base ROM)

## Emulator features
- **PKForge integration**: hand Pokémon to / from the PKForge app (export and import of party / box data)
- **Trading between games** built in: move Pokémon between save files on the same device (e.g. two Unbound saves, or between supported games later)
- **Link play** (link-cable emulation over Wi-Fi) — the bottom screen is already ready for link battles
- **Display**: CRT / LCD filters and shaders, colour correction, integer scaling options (pixel-perfect is in)
- **Cheats**: GameShark / CodeBreaker codes with a manager on the bottom screen (RetroAchievements pauses while cheats are on)
- **Hotkeys**: remappable buttons and shortcuts (fast forward, save / load state, screenshot, menu)
- **Audio**: per-channel volume, low-pass filter
- **Rewind** and turbo settings
